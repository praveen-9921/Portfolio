# 🚀 Praveen Kumar – Developer Portfolio


A modern, responsive developer portfolio built with React and Vite. Showcases projects, skills, education, certifications, and contact information with a clean, professional design.

---

## ✨ Features

- 🎨 **Beautiful glassmorphic UI**
- 📱 **Fully responsive** (mobile, tablet, desktop)
- 🧑‍💻 **Animated scroll-to-show sections**
- 🏆 **Featured & notable projects** with images
- 🛠️ **Skills, education, and certifications timeline**
- 📬 **Contact section** with social links & resume download
- 🦶 **Footer** with navigation and social icons

---

## 🛠️ Tech Stack

- ⚛️ **React** (with hooks)
- ⚡ **Vite** (for fast development)
- 🎨 **CSS Modules** (modular, maintainable styles)
- 💎 **Ionicons** (icon library)
- 🖼️ **Unsplash** (project images)

## 🏁 Getting Started

1. 📦 **Clone the repository:**
   ```bash
   git clone https://github.com/praveen-kumar-dev/portfolio.git
   cd portfolio
   ```
2. 📥 **Install dependencies:**
   ```bash
   npm install
   ```
3. 💻 **Start the development server:**
   ```bash
   npm run dev
   ```
4. 🌐 **Open in your browser:**
   Visit [http://localhost:5173](http://localhost:5173)
